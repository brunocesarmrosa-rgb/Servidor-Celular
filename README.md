# Servidor-Celular — Taikazet

Agente de sugestão de produtos que **pensa no celular** (Termux + llama.cpp, 100% local) e **fica online 24h** para o site e serviços externos via uma "caixa de correio" gratuita (Supabase). Operado pelo Claude Code.

## Em qualquer PC (Windows, celular no USB)
```
git clone https://github.com/brunocesarmrosa-rgb/Servidor-Celular
cd Servidor-Celular
claude
```
Depois cole o conteúdo de `PROMPT-INICIAL.txt`. Nas próximas vezes basta abrir o `claude` na pasta e dizer **Servidor Celular**.

Comandos: `/ferramentas` `/conectar` `/instalar` `/iniciar` `/supabase` `/telegram` `/testar` `/catalogo` `/integrar-site` `/status` `/parar`

Ferramentas: `docs/FERRAMENTAS.md` (tudo o que usamos, como instalar e executar).

Docs: `docs/ROADMAP.md` (o que falta), `docs/LOG.md` (o que foi feito), `docs/APRENDIZADOS.md` (erros resolvidos), `docs/PROS-CONTRAS.md`.
